# Actividad Sumativa - Semana 5: Sincronizando procesos en Sistemas Concurrentes

## SpeedFast

## Descripción
Este proyecto simula un conjunto de repartidores de SpeedFast que retirarn pedidos de una Zona De Carga común (recurso compartido)
y los entregan de forma concurrente. La programación de esta semana se centra en la sincronizacion.

## Estructura del Proyecto
```
src/
|__ app/
|   |__ Main.java
|__ model/
|   |__ EstadoPedido.java
|   |__ Pedido.java
|   |__ ZonaDeCarga.java
|__ services/
|   |__ Repartidor.java
```

## Instrucciones para compilar y ejecutar

1. Abrir el proyecto en el IDE
2. Verificar que la clase principal sea `app.Main`
3. Ejecutar con el botón "Run"
